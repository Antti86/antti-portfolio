# Sivustosuunnitelma

**Status:** Draft
**Alkuperäinen lähde:** [site-plan.odt](./site-plan.odt)

**Hyväksytty V1-rajaus:** [v1-scope.md](./v1-scope.md). Tämä Draft-dokumentti säilyttää alkuperäisen suunnittelutarkoituksen; V1-toteutuksessa Approved-dokumentti on ensisijainen.

## Tarkoitus

Tämä dokumentti on alkuperäisen sivustosuunnitelman Markdown-rinnakkaisversio. Se kuvaa suunniteltua sisältöä, ei valmista ominaisuusmäärittelyä. Alkuperäisessä suunnitelmassa kysymysmerkillä tai sanoilla kuten "mahdollinen" ja "myöhemmin" ilmaistut asiat säilyvät avoimina.

## Suunnitellut sisältöalueet

### Etusivu / esittely

- Lyhyt esittely ja kuva.
- Mahdollinen oma logo ja taustakuva.
- Lyhyt tagline, esimerkiksi: "Ohjelmistokehittäjäksi suuntaava varastotyöntekijä – React, Node ja Linux taustalla."
- Siirtymät CV:hen, projekteihin ja opintopolkuun.

### CV

- Web-muotoinen CV, joka sisältää:
  - työkokemuksen
  - koulutuksen ja kurssit
  - taidot
- Linkki erikseen tuotettavaan ladattavaan PDF-CV:hen.

### Projektit / Best GitHub Projects

Projektit esitetään kortteina. Suunniteltu kortin sisältö:

- nimi
- lyhyt kuvaus
- käytetyt teknologiat
- GitHub-linkki
- mahdollinen live-demo-linkki myöhemmin

Mahdollisena myöhempänä laajennuksena mainitaan tagit ja suodatus, esimerkiksi Web, Game Dev, AI ja Scripts.

### Opintopolku / kurssit

Kurssit esitetään aikajanana tai taulukkona. Suunniteltuja tietoja ovat:

- kurssi
- mahdollinen oppimispäiväkirja
- oppilaitos
- opintopisteet
- tila: suoritettu, käynnissä tai suunnitteilla

Mahdollisina ryhmittelyinä mainitaan Metropolia Open AMK, Red Hat Academy ja muut opinnot.

### Skillit / teknologiat

Teknologioille suunnitellaan CV:n taitolistausta täydentävä erillinen osio. Alkuperäisen suunnitelman ryhmät ja esimerkit ovat:

- **Frontend:** React, HTML, CSS, JavaScript
- **Backend:** Node.js, Express, REST
- **Tietokannat:** PostgreSQL, SQL
- **Cloud & Infra:** Azure, Linux, Docker/Podman, Ansible
- **Ohjelmointikielet:** Python, C++, C#, Ruby

### Kontaktit

- sähköposti
- GitHub
- mahdollinen LinkedIn-linkki myöhemmin
- yksinkertainen yhteydenottolomake, joka lähettää viestin Node-backendin kautta ja toimii samalla Node-backendin demonstraationa

## Visuaalinen suunnittelu

Alkuperäinen dokumentti jättää seuraavat teema-asiat avoimiksi:

- logo
- taustavärit
- footer
- navigointi
- fontit

## Suunnitelma ja nykyinen toteutus

### Suunnitelma

Edellä kuvatut kohdat ovat tuotteen suunnittelusuuntaa. Draft-status tarkoittaa, ettei sisältöä, rakennetta tai myöhemmiksi merkittyjä ominaisuuksia ole vielä hyväksytty lopullisiksi vaatimuksiksi.

### Nykyinen toteutus

- Frontend-sovellusta tai tässä kuvattuja näkymiä ei ole vielä toteutettu.
- Backendissä on luku- ja kehitysympäristön kirjoitusrajapintoja projekteille, kursseille ja teknologioille sekä lukurajapinnat oppilaitoksille ja oppimispäiväkirjojen metatiedoille.
- Nykyinen tietokanta yhdistää kursseja oppilaitoksiin, projekteihin, teknologioihin ja oppimispäiväkirjojen metatietoihin.
- Yhteydenottolomakkeen backendia, CV-dataa ja statistiikkatoimintoja ei ole toteutettu.
